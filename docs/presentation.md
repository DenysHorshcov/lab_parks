# План презентації (7–8 слайдів)

1. **Тема і мета.** Паралельне обчислення C(n, k) mod p і P(n, k) mod p на PARCS у Google Cloud.
2. **Задача.** Вхід `n k p`, вихід C і P за модулем p. Формули P = n·…·(n−k+1), C = P / k!, Ферма для ділення.
3. **Послідовний алгоритм.** Один цикл, O(k). Фрагмент `compute()`.
4. **Паралельний алгоритм (map-reduce).** Схема: майстер → W діапазонів → воркери (numᵢ, denᵢ) → майстер (добуток + Ферма). Комунікація O(1).
5. **Правильність.** Асоціативність множення, Ферма, Вілсон (n = p−1 → відповідь ±1), тести проти `math.comb`.
6. **Архітектура в хмарі.** Cloud Shell → `gcp_up.sh` → 1 майстер + 4 воркери n1-standard-1, europe-central2-a; firewall лише для своїх IP; `gcp_down.sh` після замірів.
7. **Результати.** Таблиця з `results/big/summary.md` + `speedup.png`.
8. **Висновки.** Прискорення близьке/далеке від лінійного і чому (накладні витрати PARCS, закон Амдала).

Питання на захисті: чому map-reduce; як ділиться робота; навіщо Ферма і чому p просте; що таке теорема Вілсона; чому прискорення не лінійне; чому код на Python 2.7.
